# chertogi-geroev-interview

Внутренний инструмент клуба **«Чертоги Героев»** для первичных собеседований мастеров НРИ.

## Что внутри

- интерактивная карточка собеседования;
- локальное автосохранение черновика;
- список сохранённых кандидатов;
- поиск по кандидатам;
- импорт/экспорт одной анкеты в JSON;
- резервный экспорт/импорт всего списка кандидатов;
- автоматическая текстовая сводка;
- печать / экспорт в PDF средствами браузера;
- встроенный регламент найма и смотрин.

## Конфиденциальность

GitHub Pages публикует только код приложения и регламент.

**Заполненные анкеты не отправляются в GitHub и не попадают в репозиторий.**
Они сохраняются только в `localStorage` текущего браузера. Для переноса между устройствами используется экспорт JSON.

Не коммитьте экспортированные анкеты кандидатов в этот репозиторий.

## GitHub Pages

После публикации репозитория сайт рассчитан на работу прямо из корня:

`https://<username>.github.io/chertogi-geroev-interview/`

- `index.html` — приложение;

- `hiring-regulations.md` — регламент;
- `.nojekyll` — отключает обработку Jekyll для статической публикации.
